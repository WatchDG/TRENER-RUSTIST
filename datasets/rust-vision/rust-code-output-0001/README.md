# rust-code-output-0001

Task set in the `jolt-tasks` format (`qa` mode, see [docs/06-data.md](../../../docs/06-data.md)) for
**vision-language models** (LFM3-VL, [docs/12-vision.md](../../../docs/12-vision.md)): a short Rust program is shown
as an image, and the task asks what number it prints (`answer_type: number`). The program is **only in the image** —
the question text is the same for every task — so the model has to read the code from the picture, and a training
step sends the gradient into the vision tower and the projector.

| Split | Tasks | Images |
|---|---|---|
| `train` | 120 | `images/train-0000.png` … `images/train-0119.png` |
| `test` | 40 | `images/test-0000.png` … `images/test-0039.png` |

## Record format

```json
{"id": "rust-code-output-0001-train-0", "question": "The image shows a Rust program. What number does it print? Answer with the number.", "answer": "72", "reason": "a * b + c = 4 * 11 + 28 = 72.", "answer_type": "number", "images": ["images/train-0000.png"], "meta": {"template": "arithmetic", "code": "fn main() { … }"}}
```

`reason` is the computation step by step (the teacher sees it with the answer); `meta.code` is the program's source
for people and is not used in training. The programs come from nine templates in turn — arithmetic, sums over
ranges (`1..n`, `1..=n`, `step_by`), `filter` + `sum`, `Vec` pushes and pops, `match` on a remainder, shadowing in a
block, slice sums, the Collatz sequence — with random parameters; no program occurs twice in the set.

## SFT corpus

The directory is also a `jolt-corpus` corpus ([docs/08-sft.md](../../../docs/08-sft.md)): `corpus.json` and
`sft.train.jsonl` / `sft.test.jsonl` — the same tasks as `kind: qa` records with the same images and the answer
"`<reason>` The program prints `\boxed{N}`." (preset `configs/smoke_sft_lfm3_vl.yaml`).

## Building

The set is generated by `scripts/make_rust_code_images_0001.py` (seed 1); `--verify` compiles and runs every program
with `rustc` and checks the answer. The images are rendered with Consolas (or DejaVu Sans Mono / Courier New), 22 px:

```powershell
$env:PYTHONUTF8 = "1"
.venv\Scripts\python.exe scripts/make_rust_code_images_0001.py --verify
.venv\Scripts\python.exe -m trener data validate datasets/rust-vision/rust-code-output-0001
```

The manifests stamp the records and the images (`images: {files, sha256}`): an edited image is caught on loading.
